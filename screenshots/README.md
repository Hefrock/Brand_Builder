# 📸 Screenshots Folder

To add screenshots to this folder without corruption, **do not use the AI chat to "add" them**. Instead:

1. Locate the **File Explorer** in the AI Studio sidebar.
2. Right-click on the `screenshots` folder.
3. Select **Upload** and choose your `.PNG` files.
4. Ensure the filenames match exactly:
   - `hero_section.PNG`
   - `billboard_view.PNG`
   - `newspaper_social_view.PNG`

*Note: Writing binary image data via the code editor or AI tools results in encoding corruption. Native uploading is required for image files.*
